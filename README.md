# Rahadian Bevan Pramudito — Portfolio

Personal portfolio website for an Electronics Engineering student at SMK Taruna Bhakti.

**Stack:** Pure HTML, CSS, and JavaScript (no frameworks). Deployed via GitLab Pages.

## Customization

- **Profile photo:** add `assets/profile.jpg` (a styled initials avatar shows until then)
- **Project photos:** add real build photos (an icon placeholder shows until then):
  - `assets/projects/running-led.jpg`
  - `assets/projects/dht11-monitor.jpg`
  - `assets/projects/7segment-counter.jpg`
  - `assets/projects/flip-flop.jpg`
- **CV:** the Download CV button opens `cv.html` — use its Print / Save as PDF button
- **GitHub:** mirror the `projects/` folders to repositories under
  [github.com/RockiStriser](https://github.com/RockiStriser) so recruiters can verify the work there too

## Local preview

Open `index.html` in a browser, or run `python -m http.server` in the project root.
